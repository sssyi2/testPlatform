````
## SSE 事件格式
每帧：`{ seq, time, runId, type, ... }`，`type` 取值：
- `snapshot`：连接建立时先推一帧现状，含 `{ status, summary, results }`
- `run:start` `{ run: {id,name,total,projectId} }`
- `run:log` `{ level: 'info'|'warn'|'error', message }`
- `case:start` `{ caseId, name, type, index, total }`
- `step:start` `{ caseId, stepId, name }`
- `step:log` `{ caseId, stepId, level, message }`
- `assertion` `{ caseId, stepId, result: AssertionResult }`
- `step:end` `{ caseId, stepId, status, durationMs }`
- `case:end` `{ caseId, name, status, durationMs, summary, result }`
- `run:end` `{ status, summary, durationMs }`

  type: 'status'|'jsonPath'|'bodyContains'|'bodyMatches'|'headerContains'|'responseTime'|'urlContains'|'elementVisible'|'elementText'|'elementCount'
  op: 'equals'|'notEquals'|'contains'|'notContains'|'matches'|'gt'|'gte'|'lt'|'lte'|'exists'|'truthy'
  path?: string; selector?: string; expected?: string; name?: string
}

export type ApiStep = {
  id: string; name: string; screenshot?: boolean; continueOnFail?: boolean
  request?: { method: string; url: string; headers?: Record<string,string>; query?: Record<string,string>; bodyMode?: 'none'|'json'|'text'|'form'; body?: string; timeoutMs?: number }
  extract?: { name: string; from: 'json'|'header'|'text'; path?: string; regex?: string; group?: number }[]
  assertions?: Assertion[]
}

export type WebStep = {
  id: string; name: string; screenshot?: boolean; continueOnFail?: boolean
  action?: { type: 'goto'|'fill'|'click'|'select'|'press'|'waitForSelector'|'waitForTimeout'|'screenshot'|'hover'|'check'; selector?: string; value?: string; url?: string; ms?: number }
  assertions?: Assertion[]
}

export type TestCase = {
  id: string; projectId: string; name: string; type: 'api'|'web'; description: string
  tags: string[]; enabled: boolean; variables: Record<string,string>; timeoutMs?: number
  steps: (ApiStep|WebStep)[]; createdAt: number; updatedAt: number
};

export type AssertionResult = { assertionId: string; type: string; op: string; label: string; expected: string; actual: string; ok: boolean; message: string }

export type StepResult = {
  stepId: string; name: string; status: 'passed'|'failed'|'error'|'skipped'; durationMs: number
  request?: { method: string; url: string; headers?: Record<string,string>; body?: string }
  response?: { status: number; headers: Record<string,string>; bodyPreview: string; bodySize: number; truncated?: boolean }
  assertions: AssertionResult[]; logs: string[]; screenshots: string[]; error?: string; extracted?: Record<string,string>; pageUrl?: string
}

export type CaseResult = { caseId: string; name: string; type: 'api'|'web'; tags: string[]; status: string; durationMs: number; steps: StepResult[]; logs: string[]; screenshots: string[]; error?: string }

export type RunSummary = {
  id: string; projectId: string; projectName?: string; name: string; status: string
  startedAt: number; finishedAt: number|null; durationMs: number|null
  summary: { total: number; passed: number; failed: number; error: number; skipped: number; durationMs: number }
  cases: { caseId: string; name: string; type: string; status: string; durationMs: number; failedAssertions: number; screenshots: string[] }[]
}

export type Run = RunSummary & { results: CaseResult[]; active?: boolean; variables?: Record<string,string>; error?: string }
````

````
# 一、被测软件（虚构的「小商城」）
`server.mjs` 同时提供 REST API 和少量服务端渲染的 HTML 页面（用于浏览器自动化测试）。

## REST API（前缀 `/api`，全部返回 JSON，UTF-8）
- `GET /api/health` → `{ status: 'ok', time }`
- `POST /api/login` body `{username, password}`：
  - 正确账号：`admin/123456`、`alice/alice123`
  - 成功 → `200 { token, user: { id, name, role } }`（token 用 `crypto.randomUUID()`，并在内存里记住）
  - 失败 → `401 { error: '用户名或密码错误' }`
- `GET /api/products?keyword=` → `{ items: [{id, name, price, stock}], total }`（keyword 为空返回全部；匹配 name 包含关键字；**至少 5 件商品**，价格用「元」为单位的数字，如 `price: 59.9`）
- `GET /api/products/:id` → 商品对象；不存在 → `404 { error: '商品不存在' }`
- `POST /api/cart/checkout`（需要请求头 `Authorization: Bearer <token>`，缺失/无效 → `401`）body `{ items: [{productId, qty}], couponCode? }` →
  `{ orderId, items, subtotal, shipping, discount, total, createdAt }`
- `GET /api/orders/:orderId`（需要 token）→ 订单；不存在 → `404`
- `GET /api/orders`（需要 token）→ `{ items: [...] }`（当前用户的订单）
- `GET /api/echo?status=500&body=xxx` → 调试用：按 query 返回指定状态码与响应体（方便平台演示各种断言）

## 结算金额规则（**这是故意埋缺陷的地方，必须严格按此实现**）
- `subtotal` = 各商品 `price * qty` 之和（保留 2 位小数）
- 正常规则应为：`subtotal >= 99` 时运费 0，否则运费 10
  - **缺陷 1**：实现里 `shipping` 永远返回 `0`（漏算了小额订单的 10 元运费）。→ 用例「小额订单应收取运费」会失败。
- 优惠券 `SAVE10` 应为「对 `subtotal` 打 9 折」（`discount = subtotal * 0.1`）
  - **缺陷 2**：实现里 `discount` 按 `(subtotal + shipping) * 0.1` 计算。→ 用例「优惠券应按商品小计计算折扣」会失败。
- 库存校验：`qty > stock` 应返回 `400 { error: '库存不足' }`
  - **缺陷 3**：实现里完全跳过库存校验，照样下单成功。→ 用例「库存不足应拒绝下单」会失败。
- `total` = `subtotal + shipping - discount`（保留 2 位小数）
- 未登录下单必须 401；订单保存进内存数组。

## HTML 页面（供 Playwright 使用，**必须带稳定选择器**）
- `GET /` → 登录页：`<input data-testid="username">`、`<input data-testid="password" type="password">`、`<button data-testid="login-btn">登录</button>`、`<div data-testid="login-error">`（错误时才显示文本「用户名或密码错误」）
- 登录成功后跳转 `/shop?token=...` → 商城页：
  - 商品列表容器 `data-testid="product-list"`，每件商品有 `data-testid="product-item"`、`data-testid="product-name"`、`data-testid="product-price"`、`<button data-testid="add-to-cart">加入购物车</button>`
  - 搜索框 `data-testid="search-input"` + `<button data-testid="search-btn">搜索</button>`（点击后按关键字过滤商品）
  - 购物车面板 `data-testid="cart-panel"`、购物车条数 `data-testid="cart-count"`、小计 `data-testid="cart-subtotal"`、优惠券输入 `data-testid="coupon-input"`、`<button data-testid="checkout-btn">结算</button>`
  - 结算结果 `data-testid="order-total"`（显示 `合计：xx 元`）
  - **缺陷 4（前端）**：点「结算」后只更新 `data-testid="order-total"` 的整数部分（例如算出 105.9 显示 `105`），并且**不显示**运费行 —— 让 Web 用例能测出「合计金额应为 105.90」失败。
- `GET /shop`（不带 token）→ 302 跳回 `/`。

其它要求：请求日志打到 stdout（形如 `[demo-app] GET /api/products 200 3ms`），启动时打印 `[demo-app] 小商城已启动：http://127.0.0.1:4517`；所有 HTML 用模板字符串生成，内联少量 CSS 让它看起来像个正常的小商城；中文文案。
````

## 一、怎么实现的：五层 + 一条执行链

```
React 界面  →  node:http 服务（零框架）  →  执行编排 runner
                                          →  执行器适配器：api.mjs / web.mjs
```

一次执行的链路：

1. 界面 `POST /api/runs` → 编排层选出用例、建 run 记录、**立刻返回 runId**（后台异步跑）；
2. 若含 Web 用例 → 启动一个 Chromium（**整个 run 复用**）；
3. 逐个用例顺序执行：合并变量（内置 → 运行级 → 用例级）→ API 用 `fetch`（`AbortController` 超时 + 流式限长 2MB 读）；Web 用**每例独立 context** 执行页面动作；

- **顺序执行**（不做并发）：日志、共享变量、浏览器上下文都可解释，避免互相干扰；
