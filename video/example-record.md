# 录像记录模板

把本文件复制成 `<录像文件名>.md`（与 mp4 同名）后填写。

- **录像文件**：`video/YYYYMMDD-xxx.mp4`
- **录制时间**：
- **录制人**：
- **录制工具**：Xbox Game Bar（Win+Alt+R） / 截图工具
- **被测软件**：名称 + 版本 + 访问地址（如 `demo-app` 小商城 http://127.0.0.1:4517）
- **测试范围**：本次覆盖的用例清单（可从平台界面导出，或直接列名称）
- **运行命令**：
  ```powershell
  node tools\demo.mjs --serve
  ```
- **平台执行 ID**：`run_xxxxxxxx`（在 `code/data/runs/` 下可找到完整结果 JSON）
- **结果**：总数 / 通过 / 失败 / 异常 / 总耗时
- **发现的缺陷**：逐条写「现象 → 期望 → 实际 → 对应断言」
- **截图证据**：`code/data/runs/<执行ID>/*.png`
- **结论**：平台是否达成"对该软件完成一轮有效测试"的目标
- **备注**：异常、翻车、重录原因等
